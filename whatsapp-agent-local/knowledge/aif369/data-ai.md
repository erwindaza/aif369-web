# Data & AI Factory — servicios de datos, ETL e integración

## Qué es la Data & AI Factory
Línea nueva de producto: una fábrica de soluciones de datos e IA para empresas que necesitan automatizar procesos, integrar información, construir pipelines y convertir sus datos en decisiones. Trabaja el "factory backlog": ETL/ELT, dashboards, APIs, calidad, trazabilidad, automatización y enriquecimiento con IA en ciclos cortos.
<!-- fuente: data-ai-factory.html, index.html -->

## Problemas que resuelve
Reportes manuales (Excel, cierres recurrentes y consolidaciones), integraciones incompletas entre APIs, archivos, bases de datos, SaaS y cloud, datos sin calidad (faltan validaciones, alertas y linaje), dashboards atrasados, backlog técnico acumulado y procesos que todavía no usan IA de forma útil.
<!-- fuente: data-ai-factory.html -->

## Paquetes comerciales de datos
Data Sprint: construir, terminar o corregir un ETL/ELT, integración o proceso específico. Dashboard Ejecutivo: servicio end to end con integración de fuentes, modelo analítico y KPIs. AI Enrichment Pipeline: enriquecimiento con IA (clasificación, normalización, matching, extracción, análisis semántico). Data Factory Cell: célula mensual de retainer con priorización semanal, desarrollo iterativo y reporte de avance. Precios no publicados: cotizar según alcance.

## Data & ETL Sprint 10 Días
Oferta de entrada para procesos de datos puntuales. Incluye levantamiento técnico, diseño del flujo de datos, construcción o ajuste del pipeline, validaciones básicas, documentación funcional/técnica y entrega operativa en el ambiente acordado. Aplica a ETLs incompletos, dashboards detenidos, reportes manuales, iniciativas cloud detenidas y falta de trazabilidad.
<!-- fuente: data-etl-sprint.html -->

## Data Integration & ETL Sprint 10 Días
Toma un problema puntual de integración y lo deja como solución operativa y documentada. Entregables: integración de múltiples fuentes, reglas para evitar duplicados, validaciones de calidad, normalización de campos, consolidación, dataset final confiable, pipeline ETL/ELT automatizado, documentación y trazabilidad del origen y transformación.
<!-- fuente: data-integration-etl-sprint.html -->

## Fuentes de datos con las que trabaja
Bases de datos, APIs, archivos Excel, CSV, JSON o Parquet, sistemas internos, ERPs y CRMs, data lakes, data warehouses, plataformas cloud, y fuentes batch o near real time. También: reportes manuales y consolidaciones multi-área.
<!-- fuente: data-integration-etl-sprint.html -->

## Stack tecnológico
GCP, AWS, Azure, BigQuery, PostgreSQL, Python, SQL, Airflow, dbt, Spark, Power BI, Looker Studio, QuickSight y OpenAI / Gemini. En implementación se declaran además Kafka, Prefect, Redshift, Snowflake, MongoDB, Pinecone, Weaviate, Kubernetes, Docker y Terraform. Principio: adaptarse al entorno actual del cliente y priorizar herramientas que su equipo pueda operar.

## Método de trabajo (4 pasos)
1. Diagnóstico: alcance, fuentes, restricciones y entregable esperado. 2. Diseño: arquitectura, modelo de datos, controles y plan de ejecución. 3. Construcción: desarrollo iterativo con validaciones y revisión de negocio. 4. Entrega: documentación, handover, próximos pasos y soporte acordado. La ruta DEV/QA/PROD se define antes de construir.
