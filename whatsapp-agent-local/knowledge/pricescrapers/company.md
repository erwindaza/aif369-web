# PriceScrapers

## Enfoque
PriceScrapers atiende desarrollo de software full stack, aplicaciones web, backend, APIs, scraping, automatizaciones e integraciones.

## Servicios confirmados
- Desarrollo full stack de aplicaciones web.
- Desarrollo backend y APIs.
- Scraping y extraccion de datos publicos o autorizados.
- Integraciones entre sistemas.
- Dashboards, portales, herramientas internas y automatizaciones.

## Reglas comerciales
No hay precios, plazos ni condiciones contractuales confirmadas en esta base. Para cotizar se necesita alcance, usuarios, integraciones, fuentes de datos, prioridad y ambiente de despliegue.

## Preguntas utiles
Preguntar que software quiere construir, quienes lo usan, que sistemas integra, que datos necesita y para cuando.
